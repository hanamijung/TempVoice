# Discord Temporary Voice Channels (หลายเซิร์ฟเวอร์)

## ความต้องการ
- Node.js **22.13 ขึ้นไป** (ใช้ `node:sqlite` ที่มาพร้อม Node ไม่ต้องติดตั้งไลบรารีฐานข้อมูลเพิ่ม)

## วิธีติดตั้ง
1. สร้างบอทที่ https://discord.com/developers/applications แล้วคัดลอก Token
2. เชิญบอทเข้าเซิร์ฟเวอร์ ด้วย scope `bot` + `applications.commands`
   และสิทธิ์: Manage Channels, Move Members, Connect, View Channel
3. คัดลอก `.env.example` เป็น `.env` แล้วใส่ TOKEN
4. รัน:
   ```
   npm install
   npm start
   ```
5. ในแต่ละเซิร์ฟเวอร์ ให้แอดมินพิมพ์ `/setup voice-temp` แล้วลากห้อง Join ไปวางในหมวดที่ต้องการ

## คำสั่ง setup (ต้องมีสิทธิ์ Manage Server)
1. พิมพ์ `/setup voice-temp` -> บอทสร้างห้อง "➕ Join to Create" ให้
2. **ลากห้องนั้นไปวางในหมวดหมู่ที่ต้องการ** แค่นี้ก็ใช้งานได้ ห้องส่วนตัวจะถูกสร้างในหมวดที่ห้อง Join อยู่ ณ ตอนที่มีคนเข้า (ย้ายไปหมวดอื่นทีหลังก็ได้)
3. อยากได้หลายหมวดหมู่ ให้พิมพ์ `/setup voice-temp` อีกรอบ แล้วลากห้องใหม่ไปวางหมวดอื่น (สูงสุด 25 ห้องต่อเซิร์ฟเวอร์)

**ขีดจำกัด:** แพ็กเกจฟรี **5 ห้อง Join ต่อเซิร์ฟเวอร์** / Premium สูงสุด 25 ห้อง (แก้ค่าได้ที่ `FREE_MAX_CREATORS` และ `PREMIUM_MAX_CREATORS` ใน `index.js`)

ตัวเลือกเสริมของ `/setup voice-temp`:
- `category`: สร้างห้อง Join ในหมวดหมู่ที่เลือกเลย ไม่ต้องลากเอง
- `channel`: ใช้ห้องเสียงที่มีอยู่แล้วเป็นห้อง Join

คำสั่งอื่น:
- `/setup list` ดูห้อง Join ทั้งหมดและหมวดหมู่ที่แต่ละห้องอยู่
- `/setup remove channel:<ห้อง>` เลิกใช้ห้อง (ติ๊ก `delete_channel` เพื่อลบห้องทิ้งด้วย)

## การทำงาน
- เข้าห้อง Join to Create -> บอทสร้างห้องใหม่ในหมวดเดียวกัน (Bitrate สูงสุด) แล้วย้ายผู้ใช้เข้าไป
- ไม่มีคนจริงเหลือในห้อง (ไม่นับบอท) -> ลบห้องอัตโนมัติ
- เจ้าของออกแต่ยังมีคนอยู่ -> โอนความเป็นเจ้าของให้คนถัดไป
- เจ้าของห้องแก้ไขห้องได้จาก Edit Channel ปกติ หรือใช้ `/vc rename|limit|lock|unlock|transfer`
- ข้อมูลเก็บใน SQLite ที่ `./data/bot.db` (เปลี่ยนที่เก็บได้ด้วย `DB_PATH` ใน `.env`)
- ถ้ามี `data.json` จากเวอร์ชันเก่า บอทจะย้ายเข้า SQLite ให้อัตโนมัติตอนเปิดครั้งแรก แล้วเปลี่ยนชื่อไฟล์เป็น `data.json.migrated`

## Premium
เซิร์ฟเวอร์จะนับเป็น Premium ได้จากอย่างใดอย่างหนึ่ง
1. **Role ในเซิร์ฟเวอร์ซัพพอร์ตของบอท (แนะนำ):** ใส่ `SUPPORT_GUILD_ID` และ `PREMIUM_ROLE_ID` ใน `.env`
   - ใครมี Role นี้ในเซิร์ฟเวอร์ซัพพอร์ต = เป็น Premium
   - เซิร์ฟเวอร์ไหนที่ **เจ้าของเซิร์ฟเวอร์** หรือ **คนที่พิมพ์ `/setup`** มี Role นี้ จะตั้งห้อง Join ได้ถึง 25 ห้อง
   - บอทต้องอยู่ในเซิร์ฟเวอร์ซัพพอร์ต และไม่ต้องเปิด Privileged Intent เพิ่ม (เช็ก Role ผ่าน API แล้วจำผลไว้ 60 วินาที)
   - ใส่ลิงก์เชิญเซิร์ฟเวอร์ซัพพอร์ตไว้ใน `PREMIUM_URL` จะมีปุ่มพาไปสมัครตอนชนขีดจำกัด
   - ให้ Role ได้ด้วยวิธีไหนก็ได้ เช่น ให้บอทอื่นแจก หรือเชื่อมกับ Patreon/Ko-fi/Boost
2. **มอบสิทธิ์เอง:** ใส่ไอดีผู้ใช้ของคุณใน `OWNER_IDS` แล้วพิมพ์ `/premium grant guild_id:<ไอดีเซิร์ฟเวอร์>` (ยกเลิกด้วย `/premium revoke`)
3. **Discord App Subscriptions:** สร้าง SKU ในหน้า Developer Portal (ต้องเปิด Monetization) แล้วใส่ `PREMIUM_SKU_ID` ผู้ใช้จะเห็นปุ่ม Premium ตอนชนขีดจำกัด

- `/premium status` ดูแพ็กเกจ เหตุผลที่เป็น Premium และจำนวนห้องที่ใช้ไป
- ขีดจำกัดตรวจตอน **เพิ่มห้อง Join ใหม่** เท่านั้น ถ้า Role/Premium หมด ห้องที่ตั้งไว้แล้วยังใช้งานต่อได้ แต่เพิ่มใหม่ไม่ได้จนกว่าจะเหลือไม่เกิน 5
